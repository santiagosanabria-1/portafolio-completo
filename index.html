01 — Sobre mí

Software que ahorra tiempo real a las personas que lo usan.

03 — Proyectos

Trabajo seleccionado.

Proyectos propios, con el estado real de cada uno. Solo enlazo repositorios y demos que existen.

  1. 01 Full stack · IA · En desarrollo activo

    TeacherTools

    Workspace para docentes: planes de clase, quizzes, rúbricas e informes, con un AI Copilot como punto de entrada.

    Problema
    Preparar clases y evaluaciones consume horas de trabajo docente, con el material disperso entre documentos.
    Solución
    Backend Express con JWT en cookie httpOnly y límites Free/Pro validados en servidor; IA con proveedores intercambiables y RAG sobre planes de área con pgvector y embeddings locales. 126 pruebas de integración contra PostgreSQL real.
    • React 19
    • Vite
    • Express
    • PostgreSQL
    • Prisma
    • pgvector
    • Docker

    Repositorio privado — código disponible para revisión bajo solicitud.

  2. 02 Full stack · SaaS

    Black Crown Barber

    Plataforma de gestión para una barbería: reservas, dashboard, POS, CRM, contabilidad e inventario.

    Problema
    Reservas, caja, clientes e inventario gestionados a mano o en herramientas separadas.
    Solución
    Reservas públicas sin registro, panel interno con autenticación JWT y API REST en Express + MongoDB. Frontend React/TypeScript empaquetado también como app Android con Capacitor.
    • React
    • TypeScript
    • Tailwind
    • Zustand
    • Express
    • MongoDB
    • Capacitor
    Código en GitHub (se abre en una pestaña nueva) Demo del frontend (se abre en una pestaña nueva)

  3. 03 Frontend · JavaScript vanilla

    CineVerse

    Sistema de cartelera y venta de entradas de cine, sin frameworks ni backend propio.

    Problema
    Simular la operación de un cine —funciones, asientos y venta— evitando que dos personas compren el mismo asiento.
    Solución
    Datos reales de TMDB, mapa de asientos interactivo, reservas con prevención de doble venta, pasarela de pago simulada y tickets imprimibles, persistidos en localStorage.
    • HTML
    • CSS
    • JavaScript ES6+
    • TMDB API
    • GSAP
    • localStorage
    Código en GitHub (se abre en una pestaña nueva)

  4. 04 Backend · IA · En desarrollo

    EduConta AI

    Asistente contable y financiero para la gestión administrativa de una institución educativa.

    Problema
    Matrículas, pensiones, pagos, facturas y proveedores gestionados en hojas de cálculo, sin trazabilidad.
    Solución
    API NestJS modular sobre PostgreSQL con Prisma, auditoría de operaciones y documentación Swagger; un agente de IA en n8n responde consultas en lenguaje natural apoyándose en los endpoints del backend.
    • NestJS
    • TypeScript
    • PostgreSQL
    • Prisma
    • Passport JWT
    • n8n
    • Docker

    Repositorio privado — en construcción.

04 — Proceso

Cómo llevo una idea a producción.

  1. 01

    Descubrir

    Entender quién usa el sistema y qué problema concreto resuelve antes de escribir código.

  2. 02

    Diseñar

    Modelo de datos, contratos de API y flujos de interfaz definidos en un plan explícito.

  3. 03

    Construir

    Cambios incrementales, con Git Flow y commits convencionales, verificables en cada paso.

  4. 04

    Probar

    Tests de integración contra una base real y revisión en varios anchos de pantalla.

  5. 05

    Desplegar

    Docker Compose para servicios; Vercel y GitHub Pages para frontends estáticos.
